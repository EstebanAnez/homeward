# Homeward

Help that actually makes it home.

Homeward helps a family caregiver plan the first 72 hours after a hospital discharge: it finds what is still missing, asks the right people, shows who pays, and checks that each thing really arrived and could be used.

**Live preview:** https://estebananez.github.io/homeward/

Prototype for KU's "The First 72 Hours" Digital Health Venture Challenge (October 2026).

- This public preview plans with built-in rules. The full version (hosted on Claude) adds AI that reads the discharge paper and live links for helpers to accept tasks.
- Local resources are real Lawrence / Douglas County programs, checked Oct 9, 2026. Always call to confirm.
- Payments and the hospital support budget are simulated. Plans practical, non-clinical help only. Not HIPAA-compliant: use first names only.
